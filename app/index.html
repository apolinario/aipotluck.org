Methodology · footnote

How the red spots were drawn.

We adapted Chip Huyen's 900-repo survey methodology: filter GitHub for AI-relevant repositories with meaningful activity (commits in 90 days, ≥500 stars), classify by stack layer, then score each category on five dimensions — completeness, interoperability, documentation, governance, and safeguards. Categories below the 40th percentile on the composite score are marked as gaps. Every score is reproducible from methodology.md; every project is editable by pull request.
