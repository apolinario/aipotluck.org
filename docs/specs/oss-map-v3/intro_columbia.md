# Intro

This map is built on the openness framework from the **Columbia Convening on Openness in AI** (Basdevant, François, Bdeir, Behlendorf, Kapoor, Lambert, LeCun, Surman, et al., *"Towards a Framework for Openness in Foundation Models,"* [arXiv:2405.15802](https://arxiv.org/abs/2405.15802); see also the 2025 follow-on, [arXiv:2506.22183](https://arxiv.org/abs/2506.22183)). We adopt its central insight: openness in AI is not binary and not software-only. It varies across the stack — at the model level (datasets, code, weights), in the system around it (infrastructure below, product and UX above), and across cross-cutting attributes: documentation, licensing, and safeguards.

So we score every product on three independent questions. **Is it open?** — graded with the [Model Openness Framework](https://arxiv.org/abs/2403.13784), because "open weights" rarely means "open source." **Is it used?** — real adoption, not GitHub stars. **Is it good?** — measured against community benchmarks where they exist, and stated plainly where they don't. The interesting findings live where these disagree: the widely-used model that is barely open, the fully-open project few have adopted yet. Every score is sourced and every method is labeled, so the community can check, challenge, and improve it.
