# v3 of the Open Source AI Map — review

We've re-based the map on the Columbia openness framework. Three changes we'd value your read on:

1. **Categories** now follow the paper's stack — model datasets / code / weights, the system layers, and the cross-cutting attributes (documentation, licensing, safeguards). We kept the recognizable product categories from v1 as the shelves and aligned each to the framework; the framework's depth lives in the openness *scoring*, not in adding more shelves.

2. **Scoring is now three axes — openness, adoption, capability** — instead of a single competitive verdict. Openness is graded with the Model Openness Framework (open-source vs open-weights vs closed), so the map shows the distinction directly: e.g. a fully-open model like OLMo 2, an open-weights model under a restrictive license like Llama 4, and an open-weights model under a permissive MIT license like DeepSeek all land in different places.

3. We **re-based off the foundational framework directly** and score openness bottom-up from each product's released components, every value sourced.

**Where your steer would help most:**
- Do the categories read right to you?
- Anything mis-scored on openness for the flagship models?
- The handful of categories with no clean home in the framework (evaluation harnesses, compilers, governance) — keep-and-flag, or handle differently?
